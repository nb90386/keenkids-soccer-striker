# KeenKids Soccer Striker: Scratch lesson kit

A 67-slide coding-club lesson for KeenKids Enrichment (grades 3–4) in which students build a soccer game in Scratch 3: player movement, dribbling, shooting, a goalie, a score and a clock, plus bonus challenges C1–C4. The deck, PDF and teacher guide are generated by a Node pipeline, and every coding slide is machine-checked against a working reference project.

## Rebuild

```sh
cd build
npm ci
./build_all.sh   # zsh; writes build/render/ and refreshes output/
```

`build/browser.js` launches Playwright's `chromium_headless_shell-1254` from `~/Library/Caches/ms-playwright/` (the build matching `playwright-core` 1.65.1). Install it with Playwright's installer, or edit `browser.js` to point at another Chromium. The Chromium steps fail inside the Claude Code macOS sandbox, so run them outside it.

## Verification

`verify_code.mjs` parses each slide's blocks with scratchblocks' own parser and checks them against `project.json` from the reference `.sb3`: known Scratch 3 blocks only, 1–3 new blocks per slide, and the same sprite, opcodes, nesting, order and literal values.

Re-run on 2026-11-22: **42 of 43 coding slides pass.** The one failure is slide 52, which shows `FULL TIME!` while the reference project says `FULL TIME! 🏁`. It is a known, documented difference (see `output/QA_REPORT.md`). Deck rendering and gameplay tests were not re-run for this import.
